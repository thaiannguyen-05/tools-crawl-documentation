① Entry points

A. Crawl + streaming vectorize

crawl.py:556 _execute_crawl_batch → crawl.py:95 crawl_single_topic → crawl.py:36 _handle_document_record

  • Sources: GitHub md, Wikipedia txt, DDG pdf/docx, curated seeds, catch-up loop.
  • Per download → process_file_to_vector(..., save_db, db_url) → append CSV row → optional --delete-raw.
  • Flags: --process / --delete-raw / --save-db / --db-url / --fast-test

B. Existing folders → CSV + DB

crawl.py:523 _execute_local_folders / processor.py:242 generate_training_data

  • Each level-1 subfolder = 1 label. collect_files_by_label().
  • Append mode: loads old CSV, dedups on (label, file_name).
  • Calls process_file_to_vector(save_db, db_url) per file.

C. Upload-triggered ingest

file_process/classify_file.py:24 ingest_file_name (alias classify_file_name giữ tương thích NestJS)

  • extract_file(fileName) → ingest_document() → save_ingested_document() → retrieve_similar_documents().
  • CLI: python -m file_process.classify_file <fileName> [--no-db] [--no-retrieve]. Fail-open exit 0.

② Per-file pipeline (core)

processor.py:121 process_file_to_vector()

1
Extract — extract_text(name, bytes). Handles .doc → .extracted.txt companion. Empty / no-section → skip (None).
2
Chunk — chunk_document(doc). No chunks → skip.
3
Embed — per chunk: chunk_to_input → segment_vietnamese → encode_fn (PhoBERT or 64-dim mock if --fast-test).
4
Aggregate — aggregate_chunk_vectors(mean|max|weighted) → single doc vector for CSV.
5
Persist (only if --save-db) — vector_store.save_ingested_document(IngestedDocument(chunks), file_name, db_url). Upsert documents + delete + re-insert document_chunks. Any exception → warn, pipeline continues.
Returns {file_name, chunk_count, vector, vector_dim} → caller writes CSV row [vector, label, file_name] (label = folder / topic, không qua predict).
Fail-open: DB down / thiếu driver → log warning, CSV vẫn ghi đủ.

file_process/pipeline.py:101 ingest_document()

Extract → chunk → embed, trả về list[ChunkWithEmbedding] (chunk + embedding, không label). Token-budget sliding-window giữ nguyên. Helpers: ingest_bytes / ingest_file.

③ Outputs

CSV
training_data.csv / .pkl

  • output/training_data.csv [vector, label, file_name], .pkl {label: [vecs]}, *_summary.json.
  • Label = folder name (path B) or topic slug (path A).

Postgres + pgvector

file_process/vector_store.py:28 — default postgresql://postgres:postgres@localhost:5433/rag

  • documents(id, fileName unique, chunkCount) — upsert, không đụng tới docType/confidence cũ.
  • document_chunks(documentId, chunkIndex, text, heading, embedding::vector(1024)) — predictedLabel/labelProbs ghi NULL.
  • Vector literal "[v1,v2,...]", <=> cosine + HNSW.
  • KNN: query_similar(emb, top_k) không lọc label, retrieve_similar_documents() dedups (fileName, chunkIndex), excludes self, returns vector_dbs[] top-K.
Path C retrieves by default (RAG_VECTOR_DB_ENABLED); --no-retrieve / --no-db disables. Top-K via RAG_RETRIEVAL_TOP_K / --top-k.

Config

  • .env.example → .env: DATABASE_URL, RAG_VECTOR_DB_ENABLED, RAG_RETRIEVAL_TOP_K.
  • file_process/settings.py resolves all of the above.
  • psycopg2-binary in requirements.txt.
Flow: Entry (A/B/C) → Extract → Chunk → Embed → Aggregate (CSV) → [Postgres nếu --save-db] → CSV + DB. Đã xóa: classifier.py, classifier-model/, mọi doc_type/confidence/predicted_label.
